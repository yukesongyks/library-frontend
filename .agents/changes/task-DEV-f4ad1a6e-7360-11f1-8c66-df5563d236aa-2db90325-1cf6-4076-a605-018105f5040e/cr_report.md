## 2. 详细发现

### [Major] CSV 注入风险 (Formula Injection)

**位置**: `src/index.ts:109-115` (`escapeCsvField` 函数)  
**描述**: 当前 CSV 转义逻辑仅处理了逗号、双引号和换行符，未对以 `=`, `+`, `-`, `@`, `\t`, `\r` 开头的字段值进行防护。攻击者可通过构造恶意输入（如 `=CMD|'/C calc'!A0`）使 Excel/LibreOffice 在打开 CSV 时执行任意公式或命令。  
**建议修复**:
```typescript
function escapeCsvField(value: unknown): string {
  const str = String(value ?? '');
  // 防止 CSV 注入：以危险字符开头时添加前缀单引号
  const dangerousPrefix = /^[=+\-@\t\r]/;
  const sanitized = dangerousPrefix.test(str) ? `'${str}` : str;
  if (sanitized.includes(',') || sanitized.includes('"') || sanitized.includes('\n')) {
    return `"${sanitized.replace(/"/g, '""')}"`;
  }
  return sanitized;
}
```
**参考**: OWASP CSV Injection Prevention
