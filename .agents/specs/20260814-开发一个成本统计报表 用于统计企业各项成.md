# 成本统计报表 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 开发企业成本统计报表系统，包含前端 Dashboard 与分析页面、后端 API 与数据聚合服务，支持多维度（部门/项目/业务线/人员/时间）人力成本与项目成本统计及报表导出。

**Architecture:** 前后端分离架构。后端基于 Spring Boot 3 + MyBatis-Plus + MySQL，提供 RESTful API 进行成本数据的 CRUD、聚合查询与导出；前端基于 React 18 + TypeScript + Ant Design 5 + ECharts，构建 Dashboard 概览页与多维度成本分析页，支持图表可视化与 Excel 导出。

**Tech Stack:**
- 前端: React 18, TypeScript 5, Ant Design 5, ECharts 5, React Router 6, Axios, xlsx (SheetJS)
- 后端: Java 17, Spring Boot 3.2, MyBatis-Plus 3.5, MySQL 8, Apache POI (Excel 导出)
- 构建: 前端 Vite 5, 后端 Maven

**跨仓依赖与现状摘要:**
- `library-frontend`: 当前仅有 README.md，需从零搭建 React 项目结构
- `library-backend`: 当前仅有 README.md，需从零搭建 Spring Boot 项目结构
- 仓间对齐点: RESTful API 契约（路径、请求/响应 DTO）、跨域配置、统一错误码

## API 契约 (仓间对齐点)

### 1. 成本汇总查询
```
GET /api/v1/cost/summary
Query Params: departmentId, projectId, businessLineId, employeeId, 
              timeDimension(MONTH|QUARTER|YEAR), startDate, endDate, page, size
Response: { code, message, data: PageResult<CostSummaryDTO> }
```

### 2. Dashboard 概览
```
GET /api/v1/cost/dashboard
Query Params: year
Response: { code, message, data: DashboardDTO }
```

### 3. 维度统计
```
GET /api/v1/cost/dimension
Query Params: dimension(DEPARTMENT|PROJECT|BUSINESS_LINE|EMPLOYEE), 
              timeDimension, startDate, endDate
Response: { code, message, data: List<DimensionStatDTO> }
```

### 4. 项目成本详情
```
GET /api/v1/cost/project
Query Params: projectId, year
Response: { code, message, data: ProjectCostDTO }
```

### 5. 报表导出
```
POST /api/v1/cost/export
Body: { dimension, timeDimension, startDate, endDate, filters }
Response: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
```

## 数据库设计

```sql
-- 部门表
CREATE TABLE department (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    parent_id BIGINT DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 业务线表
CREATE TABLE business_line (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 项目表
CREATE TABLE project (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(200) NOT NULL,
    department_id BIGINT NOT NULL,
    business_line_id BIGINT,
    budget DECIMAL(15,2) DEFAULT 0,
    status VARCHAR(20) DEFAULT 'ACTIVE',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (department_id) REFERENCES department(id),
    FOREIGN KEY (business_line_id) REFERENCES business_line(id)
);

-- 人员表
CREATE TABLE employee (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL,
    department_id BIGINT NOT NULL,
    role_type VARCHAR(20) NOT NULL COMMENT 'DEV/TEST/PRODUCT/OPS',
    monthly_cost DECIMAL(12,2) DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (department_id) REFERENCES department(id)
);

-- 成本记录表(人力成本按月记录)
CREATE TABLE cost_record (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    employee_id BIGINT NOT NULL,
    project_id BIGINT,
    year_month VARCHAR(7) NOT NULL COMMENT '格式: 2026-01',
    cost_amount DECIMAL(12,2) NOT NULL,
    role_type VARCHAR(20) NOT NULL,
    department_id BIGINT NOT NULL,
    business_line_id BIGINT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (employee_id) REFERENCES employee(id),
    FOREIGN KEY (project_id) REFERENCES project(id)
);

-- 项目预算执行表
CREATE TABLE project_budget (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    project_id BIGINT NOT NULL UNIQUE,
    total_budget DECIMAL(15,2) NOT NULL,
    actual_cost DECIMAL(15,2) DEFAULT 0,
    budget_ratio DECIMAL(5,2) DEFAULT 0 COMMENT '百分比',
    estimated_overspend DECIMAL(15,2) DEFAULT 0,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (project_id) REFERENCES project(id)
);
```

```java
package com.library.cost.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.web.cors.CorsConfiguration;
import org.springframework.web.cors.UrlBasedCorsConfigurationSource;
import org.springframework.web.filter.CorsFilter;

@Configuration
public class CorsConfig {
    @Bean
    public CorsFilter corsFilter() {
        CorsConfiguration config = new CorsConfiguration();
        config.addAllowedOriginPattern("*");
        config.addAllowedHeader("*");
        config.addAllowedMethod("*");
        config.setAllowCredentials(true);
        UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
        source.registerCorsConfiguration("/**", config);
        return new CorsFilter(source);
    }
}
```

```java
package com.library.cost.service.impl;

import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.library.cost.common.PageResult;
import com.library.cost.dto.request.CostQueryRequest;
import com.library.cost.dto.response.*;
import com.library.cost.entity.*;
import com.library.cost.mapper.*;
import com.library.cost.service.CostService;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;

import java.math.BigDecimal;
import java.math.RoundingMode;
import java.util.*;
import java.util.stream.Collectors;

@Service
@RequiredArgsConstructor
public class CostServiceImpl implements CostService {

    private final CostRecordMapper costRecordMapper;
    private final DepartmentMapper departmentMapper;
    private final ProjectMapper projectMapper;
    private final BusinessLineMapper businessLineMapper;
    private final EmployeeMapper employeeMapper;
    private final ProjectBudgetMapper projectBudgetMapper;

    @Override
    public PageResult<CostSummaryDTO> queryCostSummary(CostQueryRequest request) {
        LambdaQueryWrapper<CostRecord> wrapper = new LambdaQueryWrapper<>();
        if (request.getDepartmentId() != null) {
            wrapper.eq(CostRecord::getDepartmentId, request.getDepartmentId());
        }
        if (request.getProjectId() != null) {
            wrapper.eq(CostRecord::getProjectId, request.getProjectId());
        }
        if (request.getBusinessLineId() != null) {
            wrapper.eq(CostRecord::getBusinessLineId, request.getBusinessLineId());
        }
        if (request.getEmployeeId() != null) {
            wrapper.eq(CostRecord::getEmployeeId, request.getEmployeeId());
        }
        if (request.getStartDate() != null) {
            wrapper.ge(CostRecord::getYearMonth, request.getStartDate());
        }
        if (request.getEndDate() != null) {
            wrapper.le(CostRecord::getYearMonth, request.getEndDate());
        }

        long total = costRecordMapper.selectCount(wrapper);
        List<CostRecord> records = costRecordMapper.selectList(wrapper);

        // 按维度聚合
        Map<String, List<CostRecord>> grouped = records.stream()
            .collect(Collectors.groupingBy(r -> {
                String key = r.getYearMonth();
                if (request.getDepartmentId() == null) key += "|" + r.getDepartmentId();
                return key;
            }));

        List<CostSummaryDTO> dtos = grouped.entrySet().stream().map(entry -> {
            CostSummaryDTO dto = new CostSummaryDTO();
            List<CostRecord> group = entry.getValue();
            dto.setPeriod(group.get(0).getYearMonth());
            
            Long deptId = group.get(0).getDepartmentId();
            Department dept = departmentMapper.selectById(deptId);
            dto.setDepartmentName(dept != null ? dept.getName() : "");

            BigDecimal dev = BigDecimal.ZERO, test = BigDecimal.ZERO, 
                         product = BigDecimal.ZERO, ops = BigDecimal.ZERO;
            for (CostRecord r : group) {
                switch (r.getRoleType()) {
                    case "DEV" -> dev = dev.add(r.getCostAmount());
                    case "TEST" -> test = test.add(r.getCostAmount());
                    case "PRODUCT" -> product = product.add(r.getCostAmount());
                    case "OPS" -> ops = ops.add(r.getCostAmount());
                }
            }
            dto.setDevCost(dev);
            dto.setTestCost(test);
            dto.setProductCost(product);
            dto.setOpsCost(ops);
            dto.setTotalCost(dev.add(test).add(product).add(ops));
            return dto;
        }).collect(Collectors.toList());

        // 分页
        int page = request.getPage();
        int size = request.getSize();
        int from = (page - 1) * size;
        int to = Math.min(from + size, dtos.size());
        List<CostSummaryDTO> paged = from < dtos.size() ? dtos.subList(from, to) : List.of();

        return PageResult.of(total, page, size, paged);
    }

    @Override
    public DashboardDTO getDashboard(Integer year) {
        String start = year + "-01";
        String end = year + "-12";
        DashboardDTO dto = new DashboardDTO();

        // 总成本
        LambdaQueryWrapper<CostRecord> wrapper = new LambdaQueryWrapper<>();
        wrapper.between(CostRecord::getYearMonth, start, end);
        List<CostRecord> allRecords = costRecordMapper.selectList(wrapper);
        BigDecimal totalCost = allRecords.stream()
            .map(CostRecord::getCostAmount)
            .reduce(BigDecimal.ZERO, BigDecimal::add);
        dto.setTotalCost(totalCost);
        dto.setHrCost(totalCost);

        // 按角色分类
        Map<String, BigDecimal> costByRole = new LinkedHashMap<>();
        costByRole.put("开发", allRecords.stream().filter(r -> "DEV".equals(r.getRoleType()))
            .map(CostRecord::getCostAmount).reduce(BigDecimal.ZERO, BigDecimal::add));
        costByRole.put("测试", allRecords.stream().filter(r -> "TEST".equals(r.getRoleType()))
            .map(CostRecord::getCostAmount).reduce(BigDecimal.ZERO, BigDecimal::add));
        costByRole.put("产品", allRecords.stream().filter(r -> "PRODUCT".equals(r.getRoleType()))
            .map(CostRecord::getCostAmount).reduce(BigDecimal.ZERO, BigDecimal::add));
        costByRole.put("运维", allRecords.stream().filter(r -> "OPS".equals(r.getRoleType()))
            .map(CostRecord::getCostAmount).reduce(BigDecimal.ZERO, BigDecimal::add));
        dto.setCostByRole(costByRole);

        // 按部门分类
        Map<Long, BigDecimal> deptCostMap = allRecords.stream()
            .collect(Collectors.groupingBy(CostRecord::getDepartmentId,
                Collectors.reducing(BigDecimal.ZERO, CostRecord::getCostAmount, BigDecimal::add)));
        Map<String, BigDecimal> costByDept = new LinkedHashMap<>();
        deptCostMap.forEach((deptId, cost) -> {
            Department dept = departmentMapper.selectById(deptId);
            costByDept.put(dept != null ? dept.getName() : "未知", cost);
        });
        dto.setCostByDepartment(costByDept);

        // 月度趋势
        Map<String, BigDecimal> monthlyMap = allRecords.stream()
            .collect(Collectors.groupingBy(CostRecord::getYearMonth,
                Collectors.reducing(BigDecimal.ZERO, CostRecord::getCostAmount, BigDecimal::add)));
        List<Map<String, Object>> monthlyTrend = monthlyMap.entrySet().stream()
            .sorted(Map.Entry.comparingByKey())
            .map(e -> {
                Map<String, Object> m = new HashMap<>();
                m.put("month", e.getKey());
                m.put("cost", e.getValue());
                return m;
            }).collect(Collectors.toList());
        dto.setMonthlyTrend(monthlyTrend);

        // 项目预算汇总
        List<ProjectBudget> budgets = projectBudgetMapper.selectList(null);
        BigDecimal totalBudget = budgets.stream().map(ProjectBudget::getTotalBudget)
            .reduce(BigDecimal.ZERO, BigDecimal::add);
        BigDecimal totalActual = budgets.stream().map(ProjectBudget::getActualCost)
            .reduce(BigDecimal.ZERO, BigDecimal::add);
        dto.setProjectTotalBudget(totalBudget);
        dto.setProjectTotalActual(totalActual);

        // 超支TOP5
        List<ProjectCostDTO> topOverspend = budgets.stream()
            .filter(b -> b.getEstimatedOverspend().compareTo(BigDecimal.ZERO) > 0)
            .sorted((a, b) -> b.getEstimatedOverspend().compareTo(a.getEstimatedOverspend()))
            .limit(5)
            .map(b -> {
                ProjectCostDTO p = new ProjectCostDTO();
                p.setProjectId(b.getProjectId());
                Project proj = projectMapper.selectById(b.getProjectId());
                p.setProjectName(proj != null ? proj.getName() : "");
                p.setBudget(b.getTotalBudget());
                p.setActualCost(b.getActualCost());
                p.setBudgetRatio(b.getBudgetRatio());
                p.setEstimatedOverspend(b.getEstimatedOverspend());
                return p;
            }).collect(Collectors.toList());
        dto.setTopOverspendProjects(topOverspend);

        return dto;
    }

    @Override
    public List<DimensionStatDTO> getDimensionStats(String dimension, String timeDimension,
                                                     String startDate, String endDate) {
        LambdaQueryWrapper<CostRecord> wrapper = new LambdaQueryWrapper<>();
        if (startDate != null) wrapper.ge(CostRecord::getYearMonth, startDate);
        if (endDate != null) wrapper.le(CostRecord::getYearMonth, endDate);
        List<CostRecord> records = costRecordMapper.selectList(wrapper);

        BigDecimal grandTotal = records.stream()
            .map(CostRecord::getCostAmount).reduce(BigDecimal.ZERO, BigDecimal::add);

        Map<Long, List<CostRecord>> grouped;
        switch (dimension) {
            case "DEPARTMENT" -> grouped = records.stream()
                .collect(Collectors.groupingBy(CostRecord::getDepartmentId));
            case "PROJECT" -> grouped = records.stream()
                .filter(r -> r.getProjectId() != null)
                .collect(Collectors.groupingBy(CostRecord::getProjectId));
            case "BUSINESS_LINE" -> grouped = records.stream()
                .filter(r -> r.getBusinessLineId() != null)
                .collect(Collectors.groupingBy(CostRecord::getBusinessLineId));
            case "EMPLOYEE" -> grouped = records.stream()
                .collect(Collectors.groupingBy(CostRecord::getEmployeeId));
            default -> grouped = Map.of();
        }

        return grouped.entrySet().stream().map(entry -> {
            DimensionStatDTO dto = new DimensionStatDTO();
            dto.setDimensionId(entry.getKey());
            List<CostRecord> group = entry.getValue();
            BigDecimal total = group.stream().map(CostRecord::getCostAmount)
                .reduce(BigDecimal.ZERO, BigDecimal::add);
            dto.setTotalCost(total);
            dto.setDevCost(group.stream().filter(r -> "DEV".equals(r.getRoleType()))
                .map(CostRecord::getCostAmount).reduce(BigDecimal.ZERO, BigDecimal::add));
            dto.setTestCost(group.stream().filter(r -> "TEST".equals(r.getRoleType()))
                .map(CostRecord::getCostAmount).reduce(BigDecimal.ZERO, BigDecimal::add));
            dto.setProductCost(group.stream().filter(r -> "PRODUCT".equals(r.getRoleType()))
                .map(CostRecord::getCostAmount).reduce(BigDecimal.ZERO, BigDecimal::add));
            dto.setOpsCost(group.stream().filter(r -> "OPS".equals(r.getRoleType()))
                .map(CostRecord::getCostAmount).reduce(BigDecimal.ZERO, BigDecimal::add));
            if (grandTotal.compareTo(BigDecimal.ZERO) > 0) {
                dto.setPercentage(total.divide(grandTotal, 4, RoundingMode.HALF_UP)
                    .multiply(new BigDecimal("100")));
            }
            // 设置名称
            dto.setDimensionName(resolveDimensionName(dimension, entry.getKey()));
            return dto;
        }).sorted((a, b) -> b.getTotalCost().compareTo(a.getTotalCost()))
          .collect(Collectors.toList());
    }

    private String resolveDimensionName(String dimension, Long id) {
        return switch (dimension) {
            case "DEPARTMENT" -> {
                Department d = departmentMapper.selectById(id);
                yield d != null ? d.getName() : "未知";
            }
            case "PROJECT" -> {
                Project p = projectMapper.selectById(id);
                yield p != null ? p.getName() : "未知";
            }
            case "BUSINESS_LINE" -> {
                BusinessLine b = businessLineMapper.selectById(id);
                yield b != null ? b.getName() : "未知";
            }
            case "EMPLOYEE" -> {
                Employee e = employeeMapper.selectById(id);
                yield e != null ? e.getName() : "未知";
            }
            default -> "未知";
        };
    }

    @Override
    public ProjectCostDTO getProjectCost(Long projectId, Integer year) {
        Project project = projectMapper.selectById(projectId);
        ProjectBudget budget = projectBudgetMapper.selectOne(

        ProjectCostDTO dto = new ProjectCostDTO();
        dto.setProjectId(projectId);
        dto.setProjectName(project != null ? project.getName() : "");
        if (project != null) {
            Department dept = departmentMapper.selectById(project.getDepartmentId());
            dto.setDepartmentName(dept != null ? dept.getName() : "");
            if (project.getBusinessLineId() != null) {
                BusinessLine bl = businessLineMapper.selectById(project.getBusinessLineId());
                dto.setBusinessLineName(bl != null ? bl.getName() : "");
            }
        }

        if (budget != null) {
            dto.setBudget(budget.getTotalBudget());
            dto.setActualCost(budget.getActualCost());
            dto.setBudgetRatio(budget.getBudgetRatio());
            dto.setEstimatedOverspend(budget.getEstimatedOverspend());
        }

        // 按角色统计项目成本
        String start = year + "-01";
        String end = year + "-12";
        LambdaQueryWrapper<CostRecord> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(CostRecord::getProjectId, projectId)
               .between(CostRecord::getYearMonth, start, end);
        List<CostRecord> records = costRecordMapper.selectList(wrapper);

        dto.setDevCost(records.stream().filter(r -> "DEV".equals(r.getRoleType()))
            .map(CostRecord::getCostAmount).reduce(BigDecimal.ZERO, BigDecimal::add));
        dto.setTestCost(records.stream().filter(r -> "TEST".equals(r.getRoleType()))
            .map(CostRecord::getCostAmount).reduce(BigDecimal.ZERO, BigDecimal::add));
        dto.setProductCost(records.stream().filter(r -> "PRODUCT".equals(r.getRoleType()))
            .map(CostRecord::getCostAmount).reduce(BigDecimal.ZERO, BigDecimal::add));
        dto.setOpsCost(records.stream().filter(r -> "OPS".equals(r.getRoleType()))
            .map(CostRecord::getCostAmount).reduce(BigDecimal.ZERO, BigDecimal::add));

        return dto;
    }

    @Override
    public List<ProjectCostDTO> getAllProjectCosts(Integer year) {
        List<Project> projects = projectMapper.selectList(null);
        return projects.stream()
            .map(p -> getProjectCost(p.getId(), year))
            .collect(Collectors.toList());
    }
```

```java
    @Override
    public void exportCostReport(String dimension, String timeDimension,
                                  String startDate, String endDate, 
                                  HttpServletResponse response) {
        try (Workbook workbook = new XSSFWorkbook()) {
            Sheet sheet = workbook.createSheet("成本统计报表");

            // 表头
            Row header = sheet.createRow(0);
            String[] headers = {"维度名称", "开发成本", "测试成本", "产品成本", "运维成本", "总成本", "占比(%)"};
            CellStyle headerStyle = workbook.createCellStyle();
            Font font = workbook.createFont();
            font.setBold(true);
            headerStyle.setFont(font);
            for (int i = 0; i < headers.length; i++) {
                Cell cell = header.createCell(i);
                cell.setCellValue(headers[i]);
                cell.setCellStyle(headerStyle);
            }

            // 数据
            List<DimensionStatDTO> stats = costService.getDimensionStats(
                dimension, timeDimension, startDate, endDate);
            int rowNum = 1;
            for (DimensionStatDTO stat : stats) {
                Row row = sheet.createRow(rowNum++);
                row.createCell(0).setCellValue(stat.getDimensionName());
                row.createCell(1).setCellValue(stat.getDevCost().doubleValue());
                row.createCell(2).setCellValue(stat.getTestCost().doubleValue());
                row.createCell(3).setCellValue(stat.getProductCost().doubleValue());
                row.createCell(4).setCellValue(stat.getOpsCost().doubleValue());
                row.createCell(5).setCellValue(stat.getTotalCost().doubleValue());
                row.createCell(6).setCellValue(stat.getPercentage().doubleValue());
            }

            // 自适应列宽
            for (int i = 0; i < headers.length; i++) {
                sheet.autoSizeColumn(i);
            }

            // 输出
            String fileName = URLEncoder.encode("成本统计报表.xlsx", StandardCharsets.UTF_8);
            response.setContentType("application/vnd.openxmlformats-officedocument.spreadsheetml.sheet");
```

```typescript
import { useState, useEffect, useCallback } from 'react';
import { fetchCostSummary, fetchDashboard, fetchDimensionStats, fetchAllProjectCosts } from '../api/cost';
import type { CostQueryParams, CostSummaryDTO, DashboardDTO, DimensionStatDTO, ProjectCostDTO, DimensionType, PageResult } from '../types/cost';

export function useCostSummary(initialParams?: CostQueryParams) {
  const [data, setData] = useState<PageResult<CostSummaryDTO> | null>(null);
  const [loading, setLoading] = useState(false);

  const load = useCallback(async (params: CostQueryParams) => {
    setLoading(true);
    try {
      const res = await fetchCostSummary(params);
      if (res.code === 200) setData(res.data);
    } finally {
      setLoading(false);
    }
  }, []);

  useEffect(() => { if (initialParams) load(initialParams); }, []);

  return { data, loading, load };
}

export function useDashboard(year: number) {
  const [data, setData] = useState<DashboardDTO | null>(null);
  const [loading, setLoading] = useState(false);

  const load = useCallback(async () => {
    setLoading(true);
    try {
      const res = await fetchDashboard(year);
      if (res.code === 200) setData(res.data);
    } finally {
      setLoading(false);
    }
  }, [year]);

export function useDimensionStats(dimension: DimensionType, timeDimension: string, startDate?: string, endDate?: string) {
  const [data, setData] = useState<DimensionStatDTO[]>([]);
  const [loading, setLoading] = useState(false);

  const load = useCallback(async () => {
    setLoading(true);
    try {
      const res = await fetchDimensionStats(dimension, timeDimension, startDate, endDate);
      if (res.code === 200) setData(res.data);
    } finally {
      setLoading(false);
    }
  }, [dimension, timeDimension, startDate, endDate]);

  useEffect(() => { load(); }, [load]);

  return { data, loading, reload: load };
}
```

## 仓间对齐点汇总

| 对齐点 | 后端 (library-backend) | 前端 (library-frontend) |
|--------|----------------------|------------------------|
| API 基础路径 | `/api/v1/cost/*` | `axios baseURL: '/api/v1'` |
| 统一响应格式 | `Result<T> { code, message, data }` | `Result<T>` 类型定义 |
| 分页格式 | `PageResult<T> { total, page, size, records }` | `PageResult<T>` 类型定义 |
| 时间维度枚举 | `MONTH / QUARTER / YEAR` | `'MONTH' \| 'QUARTER' \| 'YEAR'` |
| 角色枚举 | `DEV / TEST / PRODUCT / OPS` | 前端映射显示 |
| 导出接口 | `POST /api/v1/cost/export` → xlsx blob | `responseType: 'blob'` 下载 |
| 跨域 | `CorsConfig` 允许所有源 | Vite proxy `/api` → `localhost:8080` |
| 金额精度 | `BigDecimal` 2位 | `formatMoney()` 2位小数 |
